# Calculadora de Factorial

## Descripción

Ejercicio práctico desarrollado con HTML, CSS y JavaScript que permite calcular el factorial de un número ingresado por el usuario.

El programa recibe un valor numérico, realiza el cálculo mediante un ciclo `for` y muestra el resultado directamente en la página web.

## Objetivo

Practicar los fundamentos de lógica de programación mediante operaciones matemáticas, estructuras repetitivas, validación de datos y manipulación del DOM con JavaScript.

## Contexto

Ejercicio académico realizado durante mi formación en **Generation México**, como parte de las actividades prácticas de programación.

## Pasos realizados

1. Crear la estructura de la página utilizando HTML5.
2. Diseñar un campo de entrada para ingresar el número.
3. Agregar un botón para iniciar el cálculo.
4. Aplicar estilos visuales mediante CSS.
5. Capturar el evento de clic del botón con `addEventListener()`.
6. Obtener y convertir el valor ingresado mediante `Number()`.
7. Validar que el valor sea numérico y no negativo.
8. Calcular el factorial utilizando un ciclo `for`.
9. Mostrar el resultado en la página mediante `textContent`.

## Resultado

Se desarrolló una calculadora web que recibe un número y obtiene su factorial mediante un ciclo repetitivo.

El programa contempla una validación básica para evitar valores no numéricos y números negativos.

## Aprendizajes

- Fundamentos de JavaScript.
- Declaración y uso de variables.
- Conversión de datos con `Number()`.
- Validación de entradas con `isNaN()`.
- Uso de estructuras condicionales `if`.
- Implementación de ciclos `for`.
- Aplicación de operaciones matemáticas.
- Manejo de eventos con `addEventListener()`.
- Manipulación del DOM mediante `getElementById()` y `textContent`.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
